# Technology Stack

FLCAD Reverse AI is built using modern engineering technologies focused on scalability, performance and long-term maintainability.

| Layer | Technology | Purpose |
|--------|------------|---------|
| Programming Language | Python | Rapid development and engineering workflows |
| User Interface | PySide6 (Qt) | Professional desktop application |
| 3D Visualization | VTK + PyVista | High-performance scientific visualization |
| Geometry Kernel | OpenCascade *(planned)* | CAD geometry and B-Rep modeling |
| Artificial Intelligence | PyTorch | Deep Learning |
| Computer Vision | OpenCV | Image processing |
| AI Runtime | ONNX Runtime | High-performance AI inference |
| Data Storage | SQLite | Local engineering database |
| Native Format | FLG *(planned)* | Native FLCAD project format |
