# Modo Produção — Genesis v0.6.5

## Objetivo

Reconhecer vários cilindros consecutivos sem abrir manualmente
o comando a cada operação.

## Uso

No painel `Reconhecer cilindro por região`, ative:

`Modo produção: manter o comando ativo após criar`

Depois:

1. selecione sementes;
2. avalie ou recalcule;
3. abra as propriedades;
4. confirme a criação;
5. o painel de reconhecimento será aberto novamente.

Os parâmetros do último comando são preservados, permitindo
repetir rapidamente o mesmo tipo de reconhecimento em vários
furos, pinos ou colunas.

## Regras

- cancelar o painel encerra a sessão de produção;
- editar um cilindro existente não reinicia o comando;
- Undo/Redo continua registrando cada criação separadamente;
- a preferência do modo produção fica salva.
