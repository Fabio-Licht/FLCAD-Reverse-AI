# Smart Selection Engine — Genesis v0.7.1

## Destaque por tipo

- malha: clara, com arestas ciano;
- plano: verde, mais opaco e com borda espessa;
- cilindro: laranja;
- eixo: azul intenso;
- ponto: vermelho.

Ao desmarcar, a aparência anterior é restaurada, incluindo
transparência, arestas e espessura das linhas.

## Gestos

- arrastar com botão esquerdo: rotacionar;
- Ctrl + clique curto: selecionar ou desmarcar;
- seleção pela árvore: sincronizada com a viewport.

## Barra de estado

A barra informa os tipos selecionados e detecta quando existe:

- uma malha + um plano: pronto para alinhamento por plano;
- uma malha + um cilindro/eixo: pronto para alinhamento por eixo.
