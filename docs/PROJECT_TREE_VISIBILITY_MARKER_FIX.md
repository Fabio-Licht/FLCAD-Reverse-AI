# Correção do marcador da árvore — Genesis v0.7.3

O indicador azul de visibilidade ocupava a primeira coluna da
árvore, mas a largura disponível não considerava toda a
indentação dos subgrupos. Em referências como planos, o símbolo
podia avançar sobre o nome do objeto.

Correções:

- primeira coluna ampliada;
- indentação ligeiramente reduzida;
- símbolo alinhado à direita na coluna de visibilidade;
- nome alinhado explicitamente à esquerda;
- tamanho do símbolo reduzido para manter boa separação.

O marcador continua clicável e mantém a função de mostrar ou
ocultar o objeto.
