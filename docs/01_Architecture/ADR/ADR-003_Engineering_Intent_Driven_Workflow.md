# ADR-003 — Engineering Intent Driven Workflow (EIDW)

**Status:** Accepted

**Date:** 2026-08-04

**Decision Type:** Core Philosophy

---

# Context

Traditional CAD and Reverse Engineering software are based on command execution.

The user is responsible for deciding:

- Which command to execute
- In what order
- Which parameters to use
- How to recover from mistakes

As engineering workflows become more complex, this increases cognitive load and reduces productivity.

---

# Decision

FLCAD Reverse AI adopts an Engineering Intent Driven Workflow.

Instead of asking the engineer which command should be executed...

...the platform asks what the engineer wants to achieve.

The Engineering Brain becomes responsible for transforming objectives into executable engineering strategies.

# Benefits

- Engineering-oriented workflow
- Lower learning curve
- Better automation
- Consistent engineering process
- Future AI evolution
- Reduced repetitive work

---

# Human Control

Every Engineering Strategy generated by the platform shall be presented to the engineer before execution.

The engineer always has the final decision.

---

# Long-Term Vision

Engineering Intent becomes the primary interaction model inside FLCAD Reverse AI.

Commands become implementation details.

Objectives become the user interface.
