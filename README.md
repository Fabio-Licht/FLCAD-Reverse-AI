# FLCAD Reverse AI

Software profissional de Engenharia Reversa desenvolvido pela FLCAD MODEL.

## Objetivo

Desenvolver um software capaz de:

- Importar arquivos STL
- Visualizar malhas 3D
- Alinhar malhas
- Criar planos de seção
- Extrair curvas
- Gerar superfícies
- Exportar para CAD
- Utilizar Inteligência Artificial para acelerar a Engenharia Reversa
