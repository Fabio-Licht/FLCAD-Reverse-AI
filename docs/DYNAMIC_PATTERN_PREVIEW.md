# Pré-visualização dinâmica — Genesis v0.5.2

A viewport atualiza imediatamente o cilindro e todas as
instâncias enquanto o usuário altera diâmetro, centro,
orientação, extensão, quantidade, distância, passo angular,
eixo, origem, eixos derivados e pontos centrais.

O cilindro mestre usa verde forte. As instâncias usam verde
mais suave. A região reconhecida permanece amarela.

Novos reconhecimentos usam as opções lembradas pelo último
comando. A edição de um cilindro existente preserva os dados
próprios daquele objeto.
