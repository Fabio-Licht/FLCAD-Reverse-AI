# Memória do último comando — Genesis v0.5.1

O FLCAD passa a reabrir os comandos com os últimos parâmetros usados, inclusive após fechar e abrir o aplicativo.

## Dados lembrados

- reconhecimento de cilindro: raio, limite angular, sementes e mínimo de pontos;
- criação de cilindro: extensão, eixo, centro e todos os parâmetros do padrão;
- reconhecimento de plano: raio, limite angular, mínimo de pontos e escala visual.

## Restaurar padrões

Use `Configurações > Limpar dados dos últimos comandos`.
Essa ação não modifica objetos já criados.
